# 🌮 Little Taco Shop

A simple multi-page website for **The Little Taco Shop**, created as a beginner HTML project.

## 📖 About the Project

This project is a basic restaurant website built while learning HTML and practicing how to create multiple pages that connect together.

The website currently includes:

* 🏠 Home page
* 🌮 About section
* 📋 Menu section
* 📞 Contact page
* 🕐 Opening Hours page

## 📄 Pages

### Contact Us

The contact page contains a form where visitors can enter their name, email, and a message/problem. It also includes the shop's location and contact information.

### Hours

The hours page shows the shop's opening hours and includes navigation links to other parts of the website.

## 🛠️ Technologies Used

* HTML5

## 🎯 Purpose

This project was created for learning and practicing:

* HTML document structure
* Headings and paragraphs
* Navigation links
* Forms
* Labels and inputs
* Images
* Lists
* Tables/data structures
* Semantic HTML elements
* Linking multiple HTML pages together

## 🚀 How to Run Locally

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.

You can also use the **Live Server** extension in VS Code to preview the website.
